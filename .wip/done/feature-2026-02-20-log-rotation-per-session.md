# FEATURE: Ротация логов по сессиям

> Дата: 2026-02-20
> Статус: идея

## Проблема

Один общий `logs/redictum.log` растёт бесконечно. Непонятно, где начало/конец сессии. При отладке приходится вручную искать нужный запуск.

## Идея

Каждый новый запуск (interactive или daemon start) создаёт отдельный лог-файл с таймстампом.

### Формат имени

```
logs/
    redictum_20260220_125857.log    # сессия 12:58:57
    redictum_20260220_103530.log    # сессия 10:35:30
    redictum_20260219_184500.log    # вчерашняя сессия
```

### Реализация

```python
def _init_logger(self) -> logging.Logger:
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = self._log_dir / f"redictum_{timestamp}.log"
    # ...
```

### Ротация старых логов

Уже есть `storage.transcripts.max_files` — добавить аналогичный параметр:

```yaml
storage:
  logs:
    max_files: 20    # хранить последние 20 сессий
```

### Бонус

Пользователь может отправить конкретный лог одной сессии, а не весь файл с историей за всё время.

## Приоритет

Низкий — удобство, не критичный функционал.
