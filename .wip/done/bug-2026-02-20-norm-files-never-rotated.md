# BUG: Нормализованные _norm.wav файлы никогда не удаляются

> Дата: 2026-02-20
> Источник: code review
> Статус: анализ
> Приоритет: средний

## Проблема

`rotate_audio()` явно пропускает файлы с суффиксом `_norm`:

```python
wav_files = sorted(
    (p for p in self._audio_dir.glob("*.wav")
     if not p.stem.endswith("_norm")),   # ← _norm пропускаются
    key=lambda p: p.stat().st_mtime,
)
```

Сырые WAV ротируются (max_files), а нормализованные копии (`rec_*_norm.wav`) накапливаются бесконечно. При активном использовании это десятки/сотни файлов.

## Варианты фикса

**A.** Удалять `_norm` файл сразу после транскрипции (он больше не нужен).

**B.** Включить `_norm` файлы в ротацию (убрать фильтр).

**C.** Удалять `_norm` вместе с парным сырым файлом при ротации.

Рекомендация: вариант A — самый чистый. Нормализованный файл нужен только для whisper, после транскрипции он бесполезен.
